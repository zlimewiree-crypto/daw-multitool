## Files
- main.py, multitool/app.py — home screen and tool window lifecycle
- multitool/permissions.py — built-app launch checks for folders, Accessibility and Screen Recording; settings/reopen help
- multitool/scrolling.py, theme.py — shared scrolling pages and consistent studio styling across tools
- multitool/tools/ — shared registry; organizer and auto_poster adapters
- multitool/credits.py — shared saved producer-name rules and filename credits for both tools
- multitool/auto_poster/snippet.py — "best part" start finder
- multitool/auto_poster/project.py — export -> DAW project matching; opens it, presses play, records its window
- multitool/auto_poster/render.py — read-only sources -> paired wide/vertical MP4s; CLI defaults to dry-run
- multitool/auto_poster/setup_window.py — the setup wizard window (pages, Copy, clipboard/Downloads key pickup)
- multitool/auto_poster/setup_guide.py — one-time developer-app setup steps per platform (links, copy values, key boxes)
- multitool/auto_poster/accounts.py — Keychain credentials + saved app keys; browser sign-in for YouTube/TikTok/Instagram (Facebook Login)
- multitool/auto_poster/schedule.py — Post Scheduler queue (app data schedule.json), due runner, opt-in LaunchAgent (`--run-schedule`)
- multitool/auto_poster/results.py — Results Tracker: published IDs in receipts -> platform stats, cached in results.json
- multitool/library/ — Project Library tool (FL/Ableton via Auto Poster's daws + its own extra_daws/extra_project_folders for Pro Tools) (core.py scan/link/filter, ui.py window); adapter multitool/tools/project_library.py
- multitool/auto_poster/publish.py — routes saved versions to platforms; uploads, persistent IDs and duplicate protection
- multitool/auto_poster/storage.py, ui.py — settings, delivery receipts and composer/account/history window
- app_paths.py — resources/data paths, locked config transactions and shared atomic JSON saves
- config.example.json — shared defaults including auto_poster; config.json holds personal overrides (ignored)
- DAW Multitool.spec, scripts/build_app.py — versioned macOS bundle with Python, audio libraries and FFmpeg
- bounce_sorter_app.py, sorter.py — organizer UI, no-overwrite moves and journal
- drums.py, native/sound_classifier.swift — drum detector v4: macOS SoundAnalysis helper (built by build_app.py / on first use) + HPSS measurements; scripts/check_drums.py --stress retrains with altered copies in test_exports/stress
- multitool/music.py — BPM/key: file name first ("155 fmin", "C# Minor", "140bpm"), else heard (tempo candidates, key profiles)
- multitool/varispeed/ — Varispeed: core.py (speed↔semitones, typed speeds, new BPM/key names in the file's own style, FFmpeg decode + soxr VHQ render, no-overwrite save, dry-run CLI), player.py (live TapePlayer via sounddevice/PortAudio, glide in semitones/s), ui.py; settings section `varispeed`
- multitool/audio/ — the DAW Multitool audio device: build.py (compiles native/audio_device + native/audio_bridge.m into build/native/), device.py (status, install/remove as administrator via osascript; dry-run CLI), bridge.py (the helper process: commands on stdin, JSON status/events; one per app, resumes pass-through at start); settings section `audio`
- multitool/settings.py — Settings window (audio device + pass-through + how-to + about), opened by the home knob
- multitool/auto_poster/autopilot.py — watched-folder pipeline (ledger autopilot.json, claims, request building, best part, next free posting times); shared by the window, Create videos and the login helper
- scripts/live_session.py — Claude Code hook (.claude/settings.json): rewrites notes/LIVE_SESSION.md after every step so Codex can take over mid-task; holds Claude's auto-continue if files changed (AGENTS.md)
